# MCP 2026-07-28 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Metro MCP 5.0.0 as one feature PR with a stateless MCP 2026-07-28 server, 2025 stateless compatibility, MRTR station selection, Cloudflare's OAuth Provider, canonical `/mcp` authorization, rollback-safe Durable Object retirement, and production-shaped verification.

**Architecture:** An outer Worker router canonicalizes exact `/sse` POST/OPTIONS requests to `/mcp` before a per-environment `OAuthProvider` validates credentials and audience. Its protected handler creates a request-scoped `createMcpHandler` closed over `env` and validated application props; the SDK v2 factory registers the existing thirteen tools, three resources, and three prompts without protocol session state. The old `MetroMcpAgent` export and namespace remain inactive for rollback, while all new traffic uses the stateless route.

**Tech Stack:** Bun, TypeScript, Cloudflare Workers/Wrangler, `agents@0.20.1`, `@modelcontextprotocol/server@2.0.0`, `@cloudflare/workers-oauth-provider@0.10.3`, Zod 4, Vitest 4.1, `@cloudflare/vitest-pool-workers`, MCP conformance `0.2.0-alpha.11`.

## Global Constraints

- Deliver all protocol, auth, compatibility, tests, docs, and active-infrastructure cleanup in one feature PR; MCP Apps stay in the next PR.
- Target Metro MCP `5.0.0` and MCP `2026-07-28`; keep SDK v2's `legacy: "stateless"` path for ordinary 2025 tools/resources/prompts.
- Canonical OAuth resource is `${MCP_PUBLIC_ORIGIN}/mcp`; `/sse` is only an outer URL alias and never an audience.
- Exact production resource is `https://metro-mcp.anuragd.me/mcp`; exact preview resource is `https://metro-mcp-preview.anuragd.me/mcp`.
- Application permission is exactly `transit:read`; reject protected traffic unless validated props contain that scope.
- Exact runtime pins: `agents@0.20.1`, `@modelcontextprotocol/server@2.0.0`, `@modelcontextprotocol/client@2.0.0`, `@modelcontextprotocol/sdk@1.30.0`, `@cloudflare/workers-oauth-provider@0.10.3`, `zod@4.4.3`.
- `@modelcontextprotocol/sdk@1.30.0` remains only as a required Agents peer and for the inactive rollback class; new routing and feature modules import SDK v2 only.
- `@modelcontextprotocol/conformance@0.2.0-alpha.11` is an intentional prerelease pin: stable `0.1.16` has no 2026-07-28 requirement set, while alpha.11 ships the frozen `requirements/2026-07-28.yaml` manifest and `--requirements` runner.
- `bun.lock` is the sole lockfile; all CI installs use `bun install --frozen-lockfile`.
- `MCP_REQUEST_STATE_KEY` is a stable Wrangler secret of at least 32 bytes, used only by `createRequestStateCodec` with `ttlSeconds: 300`.
- Do not add a Durable Object deletion migration. Remove the active binding and routing, but retain the existing `v1` migration, `src/mcp-agent.ts`, class export, and namespace for rollback.
- Query-string credentials are ignored. No-audience tokens, `/sse`-audience tokens, and old DCR records require reauthorization at cutover.
- Existing `/mcp`-audience JWTs expire at the earlier of their embedded expiry and `2026-11-30T00:00:00Z`.
- Preserve unrelated user changes and do not deploy, create Cloudflare resources, change GitHub OAuth apps, or push until the user separately authorizes those external actions.
