Service information

Privacy, in plain language.

Metro MCP is an anonymous, read-only transit information service. You can use it without creating an account. This page explains what a request carries and where that information can go.

Last updated August 21, 2026

What a transit request includes

Your MCP client sends Metro MCP a tool name and the inputs needed to answer it. Depending on the tool, those inputs can include a city, station name or code, route or line identifier, stop identifier, or a location and search radius.

Metro MCP sends the necessary transit inputs to WMATA for DC requests and MTA for NYC requests. It returns the resulting public transit information to your client. Do not include secrets or unrelated personal information in transit inputs.

Metro-owned telemetry is allowlisted

Metro MCP writes allowlisted operational telemetry rather than copying arbitrary request data into its own records. The possible fields are a correlation identifier, protocol era and version, MCP method and tool name, endpoint alias, upstream name, request duration, and response status class.

The Metro-owned allowlist has no client identity field. It excludes request bodies, transit input values, raw errors, secrets, and full responses. Invalid and unknown fields are dropped before the record is serialized.

Edge and provider logs

Cloudflare platform and invocation logs may exist under the service operator’s Cloudflare configuration and may contain HTTP or network metadata. Their contents and retention depend on Cloudflare and the active configuration.

WMATA and MTA may also keep access or service logs when they receive upstream requests. Cloudflare and upstream provider logs and policies are outside Metro MCP’s direct control.

What Metro MCP does not do

  • Metro MCP does not sell personal information.
  • There is no advertising on the service.
  • Metro MCP does not track you across websites or apps.
  • These legal pages do not run scripts, set cookies, or use browser storage.

Questions or concerns

For help, a privacy question, or the current security-reporting route, visit Metro MCP Support. Because the service has no user accounts, there is no account profile to retrieve or delete.
