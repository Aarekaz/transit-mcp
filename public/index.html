Add Transit MCP to your MCP client

Paste the snippet for your client. No login is required; no client token or OAuth flow is required.

Add to ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "transit-mcp": {
      "url": "https://transitmcp.com/mcp"
    }
  }
}

Add to ~/.cursor/mcp.json

{
  "mcpServers": {
    "transit-mcp": {
      "url": "https://transitmcp.com/mcp"
    }
  }
}

Run in your terminal

codex mcp add transit-mcp https://transitmcp.com/mcp

For any MCP client following the Streamable HTTP convention

{
  "name": "transit-mcp",
  "url": "https://transitmcp.com/mcp",
  "transport": "streamable-http"
}
