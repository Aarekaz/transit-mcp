Add metro-mcp to your MCP client

Paste the snippet for your client.

Add to ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "metro-mcp": {
      "url": "https://metro-mcp.anuragd.me/mcp"
    }
  }
}

Add to ~/.cursor/mcp.json

{
  "mcpServers": {
    "metro-mcp": {
      "url": "https://metro-mcp.anuragd.me/mcp"
    }
  }
}

Run in your terminal

codex mcp add metro-mcp https://metro-mcp.anuragd.me/mcp

For any MCP client following the Streamable HTTP convention

{
  "name": "metro-mcp",
  "url": "https://metro-mcp.anuragd.me/mcp",
  "transport": "streamable-http"
}
