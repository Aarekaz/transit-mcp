Model Context Protocol Server

Give your AI agent
real-time transit vision

Metro-MCP connects Claude and other AI agents to live transit data from NYC Subway and DC Metro. Train positions, arrivals, delays—all in real-time through MCP.

# Setup in 4 steps:
1. Open Your MCP client Desktop
2. Add this URL: https://metro-mcp.aarekaz.workers.dev
3. Click "Connect" and authorize via GitHub
4. Start asking questions about the Metro!
# Deploy your own Cloudflare Workers instance:
$ git clone https://github.com/Aarekaz/metro-mcp.git
$ cd metro-mcp && bun install
# Get WMATA API key & setup GitHub OAuth
$ bunx wrangler kv namespace create "OAUTH_CLIENTS"
$ bunx wrangler secret put WMATA_API_KEY
$ bunx wrangler deploy
# Full guide: github.com/Aarekaz/metro-mcp#deployment

13 Powerful MCP Tools

Complete toolkit for querying transit data through the Model Context Protocol

🚉

get_station_predictions

Get real-time arrival predictions for any station. Returns next trains with line, destination, and minutes until arrival.

🔍

search_stations

Search for stations by name or code. Fuzzy matching helps find stations even with partial queries.

🚇

get_stations_by_line

List all stations on a specific transit line. Includes coordinates and transfer information.

⚠️

get_incidents

Retrieve current service alerts, delays, and disruptions across the transit system.

🛗

get_elevator_incidents

Check elevator and escalator outages at stations. Essential for accessibility planning.

📍

get_all_stations

Fetch complete list of all stations in a city with full metadata, coordinates, and line associations.

🚌

get_bus_predictions

Real-time bus arrival predictions for DC Metro bus stops. Includes route, direction, and minutes.

🗺️

get_bus_routes

List all available bus routes in DC Metro system with route numbers and descriptions.

📌

get_bus_stops

Find bus stops by route or location. Returns stop IDs, names, and coordinates.

🚍

get_bus_positions

Track live positions of all buses on a route. Real-time GPS coordinates and heading.

🚆

get_train_positions

See exact positions of all trains in the system. Track every train car in real-time.

🔄

get_station_transfers

Find all available transfers at a station. Essential for multi-line trip planning.

📋

get_route_info

Detailed information about specific routes including stops, schedules, and service patterns.

What you can build

From simple chatbots to complex routing systems

01

Conversational Transit Assistant

Build AI agents that understand natural language transit queries. "What's the fastest way to Union Station?" Your agent fetches live data and provides actual arrival times.

02

Real-time Disruption Monitoring

Create automated alerts for service changes. Your AI can monitor specific lines, detect delays, and notify users before they even leave home.

03

Multimodal Trip Planning

Combine subway and bus data to find optimal routes. AI agents can reason about transfers, wait times, and disruptions to suggest the best path.

04

Data Visualization Tools

Build interactive maps showing train positions in real-time. Perfect for dashboards, transit analytics, or just making cool visualizations.
